# 1. NEAR comme plateforme d’applications

nearcore est l’implémentation de référence du protocole NEAR. Le README le présente comme une infrastructure pour applications sans serveur et smart contracts, avec une priorité donnée à l’utilisabilité et à la scalabilité.

Le dépôt couvre le client réseau complet : il sert à comprendre l’exécution et les services sur lesquels une DApp s’appuie, pas à remplacer un SDK applicatif.
