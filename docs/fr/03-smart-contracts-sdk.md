# 3. Smart contracts et SDK

Le README référence des SDK Rust et JavaScript/TypeScript pour écrire des contrats et des fonctions d’état. Un client JavaScript permet de connecter une application à NEAR Protocol.

Le contrat porte la logique et l’état on-chain ; l’interface utilise le client pour préparer des appels, signer et afficher les résultats. Cette séparation facilite la conception d’une DApp testable et lisible.
