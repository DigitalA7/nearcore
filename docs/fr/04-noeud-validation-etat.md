# 4. Nœud, validation et état

Le dépôt contient les briques de runtime, de stockage et de synchronisation d’état, ainsi que les composants nécessaires aux validateurs. Le README renvoie à une documentation dédiée pour rejoindre le réseau comme validateur.

Une DApp doit gérer les confirmations et les indisponibilités RPC sans présenter une transaction comme définitive trop tôt. Les lectures doivent également expliciter la hauteur ou la version d’état observée.
